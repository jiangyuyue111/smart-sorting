## 🔴 三条红线（开工前必读）

**1. 同校雷同 = 全部 0 分**

赛规明写：**同校作品外形雷同，全部 0 分**。所以：
- 不参考、不借鉴本校其他队伍的外形方案
- ⚠️ **重点排查**：实验室那套 Jetson 机器视觉平台做的就是**螺栓螺母分拣装配**，与我们同域。
  详见 [docs/调研-实验室Jetson视觉平台/](docs/调研-实验室Jetson视觉平台/) —— **务必确认其作者是否同校/同实验室、是否也报了智能分拣**

**2. 非标零件必须自主设计制造**

赛规要求不允许购买成品套件拼装。用标准件（铝型材、轴承、螺栓）没问题，**非标结构件必须自己设计**。

**3. 本仓库不得出现任何非本团队代码**

实验室那套平台**没有 LICENSE**（= 保留所有权利），且内嵌 **AGPL-3.0**（Ultralytics）与 **GPL-3.0**（PyQt5），
另有海康/大恒/越疆/NVIDIA 专有 SDK。

## 一、已定的技术决策

| 项 | 决策 | 理由 |
|---|---|---|
| **主控** | **树莓派（视觉 + HDMI 屏）+ ESP32-S3（实时脉冲）双芯** | SG2002 无 HDMI；ESP32-P4 的 PWM 外设实测不可用 |
| **识别方案** | **经典 CV，不用 YOLO** | 决赛现场要换货，**必须能现场调阈值**；YOLO 换个品类就得重训 |
| **镜头** | 由包络反推 ≈ **3.6mm 焦距 + WD 250mm** | |
| **标定流程** | **先标内参去畸变，再做仿射/单应** | 3.6mm 广角畸变大，不先去畸变，仿射会系统性偏 |
| **托盘** | 160 × 160 mm | 受整机包络限制 |

### ⚠️ 结构硬约束

- **整机外形上限：350 × 350 × 450 mm**（旧方案的 420×615 台面是硬错误，已废弃）
- **卡住包络的是 X 向行程，不是高度** —— 需要 **273mm，当前只有 290mm**，余量很紧

## 四、给组员的约定

1. **提交前先 `git pull`**，避免冲突。
2. **大文件不要进仓库** —— 视频、数据集、模型权重、安装包一律走网盘，仓库只放文本和轻量资源。
   （`.gitignore` 已挡掉常见格式）
3. **不提交密钥 / 密码 / 内网地址**。
4. **新增文档放 `docs/`**，文件名用中文，能看懂为准。
5. 引用外部代码前，**先确认它的 LICENSE** —— 见上面红线 3。
