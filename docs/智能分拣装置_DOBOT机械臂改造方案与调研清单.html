实验室机械臂改造技术方案

优先复用照片中的桌面机械臂及原厂控制器，把自制分拣托盘、六个储物盒、机器视觉、机载显示和单电池供电集成为一台完整装置。照片中的型号高度疑似 DOBOT Magician；型号和附件未核实前，以下机械臂参数仅作为设计参考。

方案版本 v3 · 2026-09-27 · 参数待实验室实物核对 · 规则以赛事最新发布稿为准

先给结论

技术上可做 如果器材确为 DOBOT Magician，公开规格显示它有 4 轴、320mm 最大工作半径、500g 负载、±0.2mm 重复定位精度、158×158mm 底座和 12V/6.5A 供电。以它代替自制 XY 龙门，可以省掉一套运动机构、步进驱动和运动控制开发。参数来源：DOBOT Magician 官方产品页

先核验两个门槛 ① 机械臂本体、相机、屏幕和全部结构能否放进 350×350×450mm；② 赛事是否接受实验室已有的成品机械臂作为执行部件。规则要求自主设计分拣装置机械部分、非标件自主制造且不得购买成品套件拼装；建议将机械臂说明为实验室既有执行器，其余结构由团队设计制造，并请指导老师向赛事组确认。

照片无法确认：机械臂铭牌、Magician / Magician Lite 具体型号、控制器版本、末端夹爪/吸盘型号、气泵及电源参数。这些会改变工作空间、SDK、电气接线和抓取方案。先按文末清单调研，再冻结采购。

2. 复用机械臂的平面布局

概念上把机械臂底座放在后左角，六个盒子放后右侧，托盘放前左侧；底座中心到最远取放点约 280–300mm，低于 Magician 参考工作半径 320mm。这个坐标布局能放进 350mm 方形范围，也避免托盘直接占住机械臂底座。

边界条件：Magician 手册图示工作区顶部视角为半圆扇区，不能只用“320mm半径”判断可达。布局要按机械臂朝向旋转，使托盘与六盒落在同一可达扇区，并逐点运行仿真/低速示教。还要验证运行时机械臂连杆本身不越过 350×350 边界；若需要把机械臂架高，整机高度仍不得超过 450mm。

4. 抓取、识别与单件流程

夹具
优先复用照片中的原厂气动夹爪，给夹爪加可换的薄型软质V形指垫，减少挤压、遮挡和碰邻件。若夹爪有效开口覆盖不了40mm货物，再试原厂20mm吸盘；球锥、薄壁和贴码面需要做实物抓取矩阵。
确认抓取成功
先读原夹具是否有夹持/真空反馈。没有反馈时增加夹具在位光电或真空压力传感器；相机对抓取前后托盘做差分，双重确认，避免假抓取后空跑。
分组
类别键为“形状 + 颜色 + 可读表面信息”。二维码先解码；文字OCR规范化后比较；外形结合轮廓、角点、长宽比和多视角。类别编号稳定映射到六盒。
复拍
货物进入托盘后先俯拍；表面标记被遮挡或置信度低时，机械臂拿起并转动货物，斜视相机复拍。需确认赛事标记是否可能在底面；若是，现有夹具和4轴结构未必能读到底面，必须增加翻面工位或向赛事确认规则。

运行状态机

  1. 调试阶段完成相机标定、货物类别/盒位映射、低速路径和供电检查。
  2. 裁判发令后只按一次外置“启动”；主机立即显示“正在分拣”，锁定无线和调参入口。
  3. 托盘成像、识别全部货物、验证类别数≤6；异常时及时显示，不开始危险动作。
  4. 按避碰且距离短的顺序逐件抓取；动作由原厂控制器执行，上位机等待动作完成/错误返回。
  5. 放入对应盒，夹具释放后由相机/传感器确认；屏幕显示序号、名称、图片、成功总数。
  6. 确认显示完成后处理下一件；失败重试一次，仍失败则显示错误并安全停止或继续未完成件（由规则和实测确定）。

运行目标先定为单件平均≤8秒、12件≤120秒；这只是项目内部目标。官方发布稿明确超过15秒无动作或未显示本次信息会结束本轮，因此软件要对长动作、通信卡住和UI阻塞设超时与状态提示。

5. 单电源与电气方案

公开 Magician 参数为 12V/6.5A、最大功耗78W。建议原型验证后采用一组固定安装的 4串 LiFePO₄ 12.8V、15Ah（约192Wh）电池，BMS连续放电≥20A、峰值≥30A；经宽输入 DC/DC 形成稳定 12V 母线。机械臂单独使用稳压 12V/10A 支路，N100/屏幕按铭牌分别供电，摄像头/ESP32走受保护的5V支路；每路独立保险丝和反接保护。禁止比赛中接实验室交流适配器替代电池。

电池容量是初始规格，不是最终定值。公开最大功耗不等于本机实测值；需把机械臂加速、夹爪气泵、主机、屏幕和灯同时运行，记录峰值电流与完整调试/比赛时长，再决定15Ah是否够用及DC/DC余量。

总电源建议：主电池 → 总保险/总开关 → 稳压12V母线 → 机械臂控制器、N100、屏幕、光源分支；另一路 DC/DC 5V → ESP32-S3 / USB外设。摄像头由主机USB供电前，要核对主机USB电流和总线功耗。接线端子、保险、线径按实测峰值与长度选型。
