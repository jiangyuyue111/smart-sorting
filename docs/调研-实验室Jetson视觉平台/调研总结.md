# 调研总结：实验室 Jetson 机器视觉平台

> 2026-09-28 ｜ 对象：学校实验室的 NVIDIA Jetson Xavier NX（局域网 `192.168.100.x`）

## 一句话结论

这台机器**不是**"可以扒固件二次开发的商业盒子"，而是**一台装着别人写的机器视觉教学平台的 Jetson 开发套件**。
**代码不可复用**，但**硬件可以借来当开发验证平台**，**架构思路值得学**。

---

## 1. 设备身份

| 项 | 值 |
|---|---|
| 地址 / 账号 | 局域网 `192.168.100.x` ／ 普通用户 `yc`（有 sudo 但需密码） |
| 实为 | **NVIDIA Jetson Xavier NX Developer Kit** |
| 怎么定位的 | 只拿到一段 SSH 登录 banner → 从 `OpenSSH_8.2p1 Ubuntu-4ubuntu0.13` 断定 Ubuntu 20.04 → **扫本网段 22 端口**，唯一开放且横幅吻合的那台就是它 |
| 身份判断依据 | `/proc/device-tree/model` + `/etc/nv_tegra_release` |

> **关键否定**：Jetson 开发套件出厂即完整 Ubuntu + NVIDIA 官方源码，**不存在需要逆向的专有固件层**。
> "扒固件"这个前提不成立 —— **带壳 / 带 Linux 的设备 ≠ 有专有固件**。

## 4. 相机（本次唯一"实测通过"的）

大恒 **MER2-302-56U3C**，SN `FDS25090519`。**端到端取图验证通过，且确认什么都不用装。**

| 项 | 实测值 |
|---|---|
| 分辨率 / 格式 | 2048×1536 / **BayerRG8**（需去马赛克）· 全局快门 |
| 链路 | USB3 Vision，**5000 Mbps SuperSpeed** |
| 帧率 | **48.2 fps**（标称 56）· 机身 39.2°C |
| SDK | `gxipy 2.0.2103.9041` + `libgxiapi.so`(aarch64) |
| udev | `99-galaxy-u3v.rules` + `80-drivers-HikSDK-2bdf.rules`，用户在 `plugdev` 组 |

**★ 三个认知纠偏**（详见 [技术要点速查.md](技术要点速查.md) §1）：

1. **U3V ≠ UVC** —— 不出 `/dev/videoN`，`cv2.VideoCapture()` 读不到
2. **U3V 没有内核驱动**（走 usbfs）—— `lsmod` 空、`Driver=` 空**全是正确现象**，没有东西需要编译
3. **gxipy 是属性式 API** `cam.ExposureTime.get()`，不是 `cam.get_int_feature_value(...)`（后者**静默返回 None 不报错**）

## 6. 许可红线（三层独立死因）

1. **无 LICENSE** —— 两个主仓库 `find -iname 'LICENSE*'` 均为空 = **保留所有权利**，著作权属原作者
2. **AGPL / GPL 传染** —— vendored Ultralytics `8.3.234`（**AGPL-3.0**，来自 Gitee 的 fork）+ **PyQt5（GPL-3.0，最易漏）**
3. **四家专有 SDK 禁止再分发** —— 海康 / 大恒 / 越疆 / NVIDIA（CUDA · TensorRT · EULA）

完整速查表见 [技术要点速查.md](技术要点速查.md) §3。

## 7. 运维隐患

- Ubuntu 20.04 已 EOL，**294 个安全更新未打**
- `/opt/MVS` 权限 `drwxrwxrwx`（**全局可写**）
- eMMC 仅 14.7GB
- ⚠️ **前主人遗留数据未清**：440MB 录屏、Thunderbird 邮件、Claude Code 登录态

## 8. 对分拣项目的决策影响

**不换主控。** Jetson 只在算力上赢，而我们的经典 CV 方案用不到那个算力。

| 维度 | 结论 |
|---|---|
| 借 Jetson 当**开发验证平台** | ✅ **唯一真正有价值的复用**。它与主控树莓派**同为 aarch64 + Python**，代码可双向搬 |
| ⚠️ 硬约束 | **必须纯 OpenCV + NumPy**。一旦 `import torch` / CUDA / TensorRT，代码就**锁死在 Jetson 上，搬不回 Pi** |
| 相机 | ❌ **不建议买**。¥2000+ 爆 ¥3250 预算，全局快门在固定俯视场景没有优势 |
| 识别方案 | ⚠️ **不要为了"用上这块算力"改成 YOLO** —— "决赛现场换货要能现场调阈值"这个选经典 CV 的理由依然成立 |
